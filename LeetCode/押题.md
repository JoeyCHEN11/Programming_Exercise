## 2. 矩阵

出过图像处理相关题型

- [[48] Rotate Image](.\48.rotate-image.cpp) 顺时针旋转矩阵90度,旋转前后关系：

$$
matrix[row][col] \rightarrow matrix[col][n - row - 1]
$$

该操作与：水平翻转，然后按对角线翻转（转置）等价，或竖直反转，再按反对角线翻转。

- [[73] Set Matrix Zeroes](.\73.set-matrix-zeroes.cpp) O(1)空间解法：借用第一行和第一列做为行列标记，再使用两个标记位记录第一行和第一列是否需要置0
- [[240] Search a 2D Matrix II](.\240.search-a-2-d-matrix-ii.cpp) 杨氏矩阵搜索：Z字查找O(m + n)
- [[498] Diagonal Traverse](.\498.diagonal-traverse.cpp) 对角线遍历，斜对角线的数量有m+n-1条，在每条反对角线上，i+j的值恒定
- [[378] Kth Smallest Element in a Sorted Matrix](.\378.kth-smallest-element-in-a-sorted-matrix.cpp)
- [[427] Construct Quad Tree](.\427.construct-quad-tree.cpp) 四叉树，注意递归的划分条件, 优化：**二维前缀和模板**
- [[2684] Maximum Number of Moves in a Grid](.\2684.maximum-number-of-moves-in-a-grid.cpp) 注意审题
- [[2397] Maximum Rows Covered by Columns](.\2397.maximum-rows-covered-by-columns.cpp)  **审题！！！！！！贪心无效, dp无效, 无法建图bfs->只能回溯**
- [[909] Snakes and Ladders](.\909.snakes-and-ladders.cpp) **看到最短路径，dp贪心都不行的话应该想到bfs，直接回溯是最差方案，大概率超时**
- [[2661] First Completely Painted Row or Column](.\2661.first-completely-painted-row-or-column.cpp)
- [[867] Transpose Matrix](.\867.transpose-matrix.cpp) **矩阵转置**
- [[807] Max Increase to Keep City Skyline](.\807.max-increase-to-keep-city-skyline.cpp) 贪心：寻找在当行当列最大值中的最小值，为可以增高的上限。
- [[304] Range Sum Query 2D - Immutable](.\304.range-sum-query-2-d-immutable.cpp) 二维前缀和模板
- [[2923] Find Champion I](.\py\2923.find-champion-i.py)
